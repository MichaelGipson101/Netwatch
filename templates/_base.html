UniFi (connection discovery)

Netwatch reads which switch port each wired device is plugged into and turns it into connection suggestions. A local, read-only API key is enough. A self-hosted UniFi OS Server uses a self-signed certificate on port 11443, so either point the CA path at its certificate or uncheck verification.
